# Portfolio Polish Design

## 목표

현재 포트폴리오의 편집형 구조와 Cledyu 사례 서사는 유지하면서, 실제 화면에서 확인된 이미지 잘림·모바일 아키텍처 가독성·이력서 미완성 인상을 해소한다.

## 범위

### 1. 프로젝트 대표 시각

- Cledyu의 실제 서비스 화면은 현재처럼 화면을 채워 보여준다.
- 아키텍처 SVG를 대표 이미지로 사용하는 프로젝트는 `cover` 확대를 제거하고, 여백이 있는 `contain` 프레임으로 전체 다이어그램을 보여준다.
- 프로젝트 이미지와 제목을 같은 상세 페이지 링크로 묶어 hover 표현과 실제 동작을 일치시킨다.
- 모바일에서 카드 콘텐츠의 고정 최소 높이를 제거해 불필요한 빈 공간을 줄인다.

### 2. 프로젝트 상세 이미지

- 이미지 크기를 데이터에 추가하는 대규모 계약 변경은 하지 않는다.
- `next/image`의 비율 왜곡을 막도록 이미지 컨테이너와 `object-fit` 규칙을 정리한다.
- 동일한 아키텍처 이미지를 대표 화면과 핵심 구현에서 반복하는 프로젝트는 중복 기능 이미지를 숨기고, 아키텍처 섹션에서만 근거로 사용한다.

### 3. 모바일 아키텍처

- 데스크톱의 구성요소 그리드와 연결 흐름은 유지한다.
- 720px 이하에서는 구성요소를 가로 스크롤하는 48rem 그리드 대신 한 열 카드로 표시한다.
- 연결 흐름은 `출발 → 도착`과 설명이 한 묶음으로 읽히는 모바일 레이아웃으로 전환한다.
- 화면 밖 콘텐츠가 있다는 사실을 사용자가 추측하지 않아도 되게 한다.

### 4. 이력서와 연락 동선

- “파일이 준비되면 연결”이라는 임시 안내를 제거한다.
- 공개 이메일을 추측해서 추가하지 않는다.
- 현재 확인 가능한 GitHub와 프로젝트 사례를 중심으로 `직접 확인하기` 영역을 제공한다.
- 이력서 상단에서 GitHub와 대표 프로젝트로 바로 이동할 수 있게 유지한다.

## 비범위

- 새 UI 라이브러리나 애니메이션 도입
- 프로젝트 설명 전체 재작성
- 확인되지 않은 성과 수치나 연락처 추가
- 실제 캡처가 없는 프로젝트를 위한 가짜 화면 제작
- 홈 전체 정보 구조 재설계

## 검증

- 컴포넌트 테스트에서 프로젝트 대표 시각이 상세 링크로 동작하는지 확인한다.
- 아키텍처 테스트에서 구성요소와 연결 흐름의 의미 구조를 유지하는지 확인한다.
- 이력서 테스트에서 임시 안내가 제거되고 검증 가능한 링크가 노출되는지 확인한다.
- `pnpm test`, `pnpm lint`, `pnpm typecheck`를 실행한다.
- 1440px와 390px 화면에서 홈·Cledyu 상세·이력서를 시각 검증한다.
